# Word List

Specific terms with required spelling, capitalization, and usage rules.

## CVEs vs. Vulnerabilities

- **First usage:** "Common Vulnerabilities and Exposures (CVEs)" — spell out the full acronym with (CVEs) in parentheses.
- **After first usage:** CVEs
- **Don't use:** "CVEs" on first usage without spelling it out; "vulnerabilities" as a synonym for CVEs. Vulnerabilities is a broader term — a vulnerability can exist before it has a CVE number. Use "CVEs" or "known vulnerabilities" where applicable.

## Zero CVEs

- **Use:** "zero CVEs" (word spelled out, not "0 CVEs")
- **Use:** "zero-CVE" hyphenated when used as a direct adjective before a noun: "zero-CVE container images," "zero-CVE virtual-machine images"
- Capitalize "Zero" only at the start of a sentence.
- **Don't use:** "0 CVEs," "0-CVE container images," "low-to-no CVEs," "low CVEs." The official adjective is "zero CVEs." Avoid language implying the existence of CVEs in Chainguard products.
- On first usage in a piece, you can write "Zero Common Vulnerabilities and Exposures (CVEs)" to introduce the acronym.

## Developers vs. Engineers

- **Prefer:** engineers, software engineers
- **Acceptable as secondary:** developers

## Open Source / Open-Source

- **Use:** open source (never hyphenated, whether adjective or noun)
- **Don't use:** open-source

## FIPS

- **Always fully uppercase:** FIPS
- **First usage in formal writing:** "Federal Information Processing Standards (FIPS)"
- **After first usage:** FIPS
- **Don't use:** fips

## STIG / STIGs

- **Acronym capitalization:** STIG (or STIGs plural — the lowercase "s" makes it plural, don't capitalize it)
- **First usage in formal writing:** "Security Technical Implementation Guide (STIG)" or "Security Technical Implementation Guides (STIGs)"
- **After first usage:** STIG or STIGs

## FedRAMP

- **Capitalization:** FedRAMP (capital F, lowercase "ed," capital RAMP)
- **First usage in formal writing:** "Federal Risk and Authorization Management Program (FedRAMP)"
- **After first usage:** FedRAMP

## NIS2

- **Always fully uppercase:** NIS2
- **First usage in formal writing:** "Network and Information Security Directive (NIS2)"
- **After first usage:** NIS2

## PCI DSS

- **Always fully uppercase:** PCI DSS
- **First usage in formal writing:** "Payment Card Industry Data Security Standard (PCI DSS)"
- **After first usage:** PCI DSS

## SBOM / SBOMs

- **Acronym capitalization:** SBOM (or SBOMs plural — the lowercase "s" makes it plural)
- **First usage in formal writing:** "Software Bill of Materials (SBOM)" or "Software Bills of Materials (SBOMs)"
- **After first usage:** SBOM or SBOMs
