# Product Names and Features

Product naming is the highest-risk category in Chainguard style. Check every product mention against this reference.

Source: Chainguard's Written Style Guide, maintained by Chainguard Marketing, as of 2026-08-19. That guide is the primary authority for product names, and this file mirrors it.

## The company: Chainguard

- **Use:** Chainguard
- **Don't use:** ChainGuard, CG, chainguard

Always capitalized. The name of the company is not a product name — if the text is talking about a specific offering, name the offering (Chainguard Containers, Chainguard Libraries, etc.).

## Chainguard Containers

The container image product.

- **Use:** Chainguard Containers (capitalized proper noun, refers to the product)
- **Use:** container images (lowercase, when referring to specific images in the catalog)
- **Don't use:** Chainguard Images (old name), Chainguard Container Images (not the formal name), "Chainguard" alone when you mean the product

### Grammar rules for Chainguard Containers

- **Singular verb when referring to the product**: "Chainguard Containers **is** a fantastic product." (NOT "are.") It's a singular proper noun.
- **Single specific image**: "Chainguard's Python container image" or "the Chainguard Python image" (lowercase "image," singular verb). NOT "Chainguard's Python Image" or "the Python Chainguard Container."
- **Multiple specific images**: "Chainguard's container images for Go, Python, and Node **are**…" (lowercase "container images," plural verb). NOT "Chainguard Container Images… is…"

### Container categories

- **base images, application images, starter images** — lowercase (capitalize only at the start of a sentence).
  - Correct: "Chainguard offers tons of container base images."
  - Wrong: "Chainguard Container Base Images."
- **FIPS images, AI images** — acronym uppercase, "images" lowercase.
  - Correct: "Chainguard's AI container images…"
  - Wrong: "Chainguard offers container fips images…"

## Chainguard Libraries

The language libraries product.

- **Use:** Chainguard Libraries
- **Use:** Chainguard Libraries for Java / for Python / for JavaScript (for specific language lines)
- **Don't use:** Java Libraries / Python Libraries (doesn't signal Chainguard), Chainguard Language Libraries (not the formal name), Chainguard Libraries for Maven / for PyPI / for npm / for TypeScript (don't invent names around packaging systems)

## Chainguard VMs

The virtual machine images product.

- **Use:** Chainguard VMs
- **Use:** container host images, container hosts (for the generic description)
- **Use:** virtual-machine images (hyphenated — "virtual-machine" is an adjective here)
- **Don't use:** Chainguard Virtual Machines (not formal), virtual machine images (unhyphenated when used as an adjective)

### Grammar rules for Chainguard VMs

- **Singular verb when referring to the product**: "Chainguard VMs **is** a fantastic product." It's a singular proper noun.
- **When describing without the formal name**: "Chainguard's virtual-machine images are…" (hyphenated adjective, lowercase).

### VM categories

- **VM base images, VM application images** — lowercase, and specify "VM" to distinguish from container categories.
  - Correct: "Chainguard offers tons of VM base images."
  - Wrong: "Chainguard VM Base Images."

## Chainguard OS Packages

The enterprise-grade packages SKU.

- **Use:** Chainguard OS Packages
- **Use:** secure packages, package(s) (lowercase, for specific packages or the general term)
- **Don't use:** Chainguard Packages (not the full name), Chainguard OS (that's the operating system, not this SKU), Chainguard packages / Chainguard os packages / chainguard os packages

Do not confuse **Chainguard OS Packages** (the SKU) with **Chainguard OS** (the operating system underpinning all Chainguard products). They are different things.

## Chainguard Actions

The catalog of hardened CI/CD workflows built and maintained in the Chainguard Factory.

- **Use:** Chainguard Actions
- **Don't use:** Chainguard CI/CD Workflows (that's the description, not the name), Chainguard Action (the name is plural, after GitHub Actions)

## Chainguard Agent Skills

The catalog of hardened AI agent skills.

- **Use:** Chainguard Agent Skills
- **Don't use:** Chainguard Skills, Chainguard Agents, Chainguard AI — each means something different from "agent skills."

## Guardener

Chainguard's AI-native agent for adoption.

- **Use:** Guardener (bare, no article)
- **Don't use:** The Guardener (the old name — it no longer includes "The"), The Gardener (the name plays on "Chainguard"; spell it accordingly), Chainguard Guardener, Chainguard migration agent, Chainguard adoption agent

Name the tool when you introduce it.

The bare form replaced "The Guardener" in August 2026, so text written before then may use the old name.

## Chainguard Repository

The managed experience for pulling all Chainguard products.

- **Use:** Chainguard Repository (always spelled out)

## Chainguard Commercial Builds

## Features

### Custom Assembly

- **Use:** Custom Assembly, Chainguard's Custom Assembly feature, Chainguard Custom Assembly
- **Don't use:** custom assembly, Custom assembly, custom-assembly

Capitalize both words. Don't hyphenate.

### EOL Grace Period / End-of-Life Grace Period

- **Use:** End-of-Life Grace Period or EOL Grace Period (spell out the acronym on first use)
- **Don't use:** Eol Grace Period, eol grace period, end-of-life grace period, eol-grace-period

EOL is always fully capitalized. "End-of-Life" is hyphenated and capitalized. "Grace Period" is always capitalized when part of the feature name.

### Private APK Repositories

- **Use:** Private APK Repositories (the feature, and when referring to multiple repositories from the feature)
- **Use:** Private APK Repository (when referring to a single repository)
- **Use:** Chainguard's Private APK Repositories / Chainguard Private APK Repositories (to emphasize the Chainguard connection)
- **Don't use:** Private APK Repos (informal shorthand, not for formal writing), private apk repositories, Private Apk Repositories, Private-APK Repositories

**Verb agreement:**
- Singular verb when referring to the feature: "Private APK Repositories **is** a lifesaver."
- Plural verb when referring to multiple repositories: "The Private APK Repositories you use **are** helping…"

### The Chainguard Factory

The automation and engineering that power Chainguard products.

- **Use:** the Chainguard Factory (mid-sentence), The Chainguard Factory (sentence start)
- **Don't use:** Chainguard factory — always capitalize both words.

### Chainguard OS

The operating system underpinning all Chainguard products.

- **Use:** Chainguard OS (both words always capitalized)

### Images Catalog / Chainguard Catalog

The directory of Chainguard Containers within the Console.

- **Use:** Chainguard Catalog, Images Catalog

Don't use "Chainguard Catalog" for the free tier — that's Chainguard Catalog Starter.

## The "This Shit Is Hard" blog series
