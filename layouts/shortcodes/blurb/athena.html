Frontier AI models are uncovering vulnerabilities in open source software before traditional security tools can detect them. Chainguard Libraries helps reduce that exposure by delivering remediated artifacts through the [Athena](https://www.chainguard.dev/athena) coalition. Chainguard validates, patches, rebuilds, and tests affected packages, then makes the fixed artifacts available through Chainguard Libraries. Customers can continue using supported package versions while receiving verifiable provenance and SBOM metadata for the remediation.
