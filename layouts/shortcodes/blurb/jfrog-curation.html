Chainguard Libraries work with JFrog Curation. JFrog Catalog recognizes Chainguard-built and remediated packages before a build requests them, so you can apply Curation policies and consume Chainguard Libraries without waiting for a first-pull scan. The integration doesn't change how Chainguard serves libraries: configure Artifactory using the standard instructions, then use the resulting Artifactory repository as your Curation source.

JFrog Curation support is currently available only for Chainguard Libraries for Java.
