{{- /* Renders placeholder markers as styled elements. Writers mark a placeholder as <^>NAME<^> in prose, inline code, or code blocks. Goldmark escapes the marker to <^>, and shortcodes that emit raw HTML can leave it as <^>, so the pattern matches both forms. Usage: {{ partial "placeholders/render.html" .Content }} */ -}} {{- $marker := `(?:<|<)\^(?:>|>)` -}} {{- $pattern := printf `%s(.+?)%s` $marker $marker -}} {{- return (replaceRE $pattern `$1` . | safeHTML) -}}
