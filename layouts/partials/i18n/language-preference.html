{{- /* Remembers the reader's language and keeps them in it. - Choosing a language in the sidebar menu, or opening any page that isn't in the default language, saves that language in localStorage. - On a default-language page, a reader who prefers another language is sent to this page's translation when one exists. This runs in , before the page renders, so the English page doesn't flash first. - When no translation exists, the page stays in the default language and the sidebar menu shows a note in the preferred language. With no saved preference, nothing happens: the default language is English. */ -}} {{- $translations := dict -}} {{- range .Translations -}} {{- $translations = merge $translations (dict .Language.Lang .RelPermalink) -}} {{- end -}}
